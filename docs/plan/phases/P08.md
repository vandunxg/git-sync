## Verification and exit gate

Use the applicable `core`, `frontend`, `visual`, `security` or `native` quality profile plus the task-specific tests. A profile pass does not replace tests listed above. Provide a handoff describing exact invariants, unresolved blockers and the next ready task. Do not skip dependencies or mark a phase done before its tasks pass.

## Failure / rollback

Stop only the affected task. Revert app changes by a reviewed source diff when appropriate; never undo a remote write blindly. For uncertain GitLab outcomes use observation/reconciliation. Preserve previous verified mirrors, snapshots and user workspace data. Keep failed evidence and do not rewrite it as success.
