# Baseline storage

No visual reference PNG is included in this package. Figma read access was quota-blocked;
none of the rejected/uncorrected mockups was substituted as an approved reference.

After actual review, store design PNGs under design/ and independently accepted implementation
PNGs under implementation/. Record relative paths, hashes, viewport, review record and renderer
in docs/ui/BASELINES.json. Include an approval document under state/evidence/ or this directory.
The integrity checker does not prove visual quality or that a claimed human review is genuine;
the reviewer must inspect images and original approval evidence.
